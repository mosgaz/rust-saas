# Security Policy

## Supported Versions

Currently, only the latest `0.2.x` release is supported with security updates. 
Older versions are not maintained.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please use the [Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) feature on GitHub, or send an email to `mosgaz@list.ru`.

Please include:
- A description of the vulnerability.
- Steps to reproduce.
- Potential impact.

You should receive a response within 48 hours. If the issue is confirmed, we will release a patch as soon as possible and credit you in the release notes.
